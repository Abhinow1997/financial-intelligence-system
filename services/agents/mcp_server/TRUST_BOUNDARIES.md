# MCP Trust Boundaries

This server exposes a finance capability over the Model Context Protocol.

- **Identity / authorization:** who may call, with what scope.
- **Typed tools/resources:** schema-validated inputs and outputs.
- **Context boundary:** what data crosses in/out; redaction rules.
- **Server trust:** supply-chain risk of the MCP server itself (syllabus, Session 9).
- **Logging:** every call is traced for the observability service.
