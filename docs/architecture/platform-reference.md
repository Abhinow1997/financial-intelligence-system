# Reference Platform

Application vs **platform** vs foundation layers (syllabus, Session 11).

- **Gateway/router** - `services/gateway`
- **Model abstraction** - `services/platform/model_gateway`
- **Prompt/config registry** - `services/platform/prompt_registry`
- **Shared retrieval** - `services/rag/*`
- **Tool/skill registry** - `services/agents/tool_registry`
- **Eval service** - `services/evaluation/eval_service`
- **Policy engine** - `services/platform/policy_engine`
- **Telemetry** - `services/platform/observability`
- **Cost metering / FinOps** - `services/platform/finops`
